# La Redada

A first-person survival horror game that runs in the browser (Three.js). Level 1: *The Walk Home* + *Hammerline Depot*.

Play: open the GitHub Pages link, or run any static server in this folder (e.g. `python3 -m http.server`) and open `index.html`.

Controls: WASD move · mouse look · Shift sprint · C crouch · F flashlight · E interact/hide · Space hold breath · Tab store map · Esc pause/brightness.

A work of fiction. Voices: ElevenLabs via Higgsfield. Characters: Meshy image-to-3D via Higgsfield.
